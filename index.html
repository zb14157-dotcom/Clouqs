Welcome to the workshop

Learn Linux by doing the work

This version includes a safe, in-browser Linux-like terminal with a virtual filesystem. Commands execute inside the game sandbox—not on your iPhone, computer, or a real server. It lets you practice command syntax without risking device files.

Important distinction: this is a command simulator, not a full Linux kernel. Commands such as pwd, ls, cd, mkdir, touch, cat, echo, cp, mv, rm, chmod, whoami, grep, wc, sort, and simple pipes/redirection are implemented in the sandbox.
